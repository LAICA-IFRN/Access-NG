Como funciona o cadastro

A matrícula devolvida pelo SUAP é usada como chave: se já existir um Usuario com essa matrícula, ele é vinculado (e o nome é sincronizado); senão, um cadastro novo é criado automaticamente, mas fica pendente — sem acesso a nenhum Tartaro — até um admin aprovar em Usuários.
